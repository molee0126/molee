# 开发改动记录 · 2026-10-26

## 阶段 0/1

从空工作区创建 Flutter 工程，加入 Android/iOS 宿主及中文主题和路由。落实游客/本机档案模式、本人及成年确认、本地影像授权、美学诉求、拍摄准备、五角度前置相机向导、照片预览与确认、重拍、草稿恢复、采集完成确认和本地删除。

将界面、应用控制器、领域模型、本地仓库和平台适配分层。影像保存在私有目录，元数据采用双代文件提交；损坏文件可回退，缺少照片时回到草稿。版本顺序不依赖系统时钟单调递增，路径读取拒绝越界。保存成功后再发布状态；失败的重拍保留已提交图片。

相机按需启动，关闭录音，串行处理拍摄与释放资源，切到后台时释放，恢复时重建。拍摄预览使用内存中的图片字节，避免已清理的临时照片被继续读取。

iOS 配置相机用途、15.5 部署目标、CocoaPods 与新式 Flutter engine 注册；私有目录排除系统备份并设置 Data Protection。Android 配置相机权限、禁用录音与备份，release 清除联网权限。原生部分尚未经过设备构建与真机验证。

## AI 关键点初步接入

加入本机 ML Kit 正面检测适配、可注入接口与独立规则：无脸、多人、信息不足、姿态信息不足、侧脸未支持、原生环境不可用时返回明确状态。仅由用户主动触发，不保存成美学报告，不生成虚构点位或结果。社区桥接包和原生推理仍需 iPhone 验证。
